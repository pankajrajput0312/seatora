# Roadmap

Each phase ships working, tested software. The next phase starts only after the current one is in use.

| Phase | Scope | Exit criteria |
|---|---|---|
| 1 | Brand, design system, landing page | Public site live; design tokens enforced |
| 2 | College discovery and institute profiles | Search/filter + profile pages on sourced data |
| 3 | Cutoffs, seat matrices, historical data | Ingestion pipeline for MCC/state PDFs with provenance |
| 4 | College comparison | Side-by-side comparison, specialty-specific |
| 5 | Rank-based discovery | Historical-match results with explicit no-guarantee messaging |
| 6 | Counselling updates and announcements | Announcement directory linked to official sources |
| 7 | Student accounts, saved colleges, shortlists | Auth, StudentProfile, SavedCollege |
| 8 | Choice-filling assistance | Ordered choice lists informed by historical data |

**Current phase: Phase 1. Landing page with early-access waitlist is live; Phase 2 next.**
