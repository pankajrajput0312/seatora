# Seatora Inside App Design System: "Case sheet" (Decide)

The landing page, privacy and auth pages use the dark roook-style system in [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md). Everything under `/decide` uses this one, a light, data-first system built on **[Astryx](https://github.com/meta/astryx)**, Meta's open-source design system (`@astryxdesign/core`, `theme-neutral`). The two never share a page.

## Why it looks like this
The user is a doctor working through a live counselling round, so the app reads like a hospital **case sheet**: chart paper, white sheets, navy ink, ruled hairlines, one chart-ink blue. Numbers are the content. They are set in **Atkinson Hyperlegible Next** (Braille Institute), whose glyphs are built so that similar characters can't be confused, so a rank like 42,284 never reads as 42,824.

## Tokens
Scoped by the `.app` wrapper and by `.app [data-astryx-theme]`, both in `src/app/globals.css`. Shared components (Button, Badge, Input…) use the same token classes and restyle automatically.

| Role | Value | Tailwind / Astryx |
|---|---|---|
| Chart paper (page) | `#f3f6f9` | `bg-background` / `--color-background-body` |
| Sheet (cards, nav) | `#ffffff` | `bg-card` / `--color-background-surface` |
| Ink | `#102231` | `text-foreground` / `--color-text-primary` |

| Ruled hairline | `#d9e1e9` | `border-border` / `--color-border` |
| Chart-ink blue (text, links, accent) | `#1c5cab` | `text-sky` / `--color-accent` |

| Good / warning / critical (text-safe) | `#0a7a0a` / `#8a5a00` / `#c03030` | `text-leaf` / `text-sun` / `text-ember` |

Fonts: `--font-app`, which is Atkinson Hyperlegible Next, used for body, headings and numbers alike. There's no pixel or monospace face inside the app.

## Layout
- Astryx `AppShell` (`height="auto"`, `variant="section"`): the sticky `TopNav` carries the brand, the Compare tray button ("2/4", only when the tray has items; on phones it is a fourth item in the bottom bar) and "Back to site"; `SideNav` holds the rank "patient band" card plus 13 items in Plan (Overview, Options, Seats, Choices, Compare), Counselling and Research groups (Lucide icons). Astryx provides the skip link, the main landmark and the mobile drawer. On phones there's also a bottom bar with Options, Seats, Choices and Rank scan (Compare "2/4" in its place while the tray has items). Nothing floats over the page, and `scroll-padding` (globals.css) sits above the header and bottom-bar heights, so a focused control is never hidden.
- The profile dialog renders inside `.app` (no portal), so it uses these tokens. With no profile saved or in the address it is the first-run setup: three steps (rank, category and PwD; courses as exact degree and specialty pairs; quotas), then Options, which opens on the current round's seats. `SetRankPrompt` starts it, and says "Loading" (never "set your rank") while a saved profile is read.
- Overview leads with what's open now (`RoundStatusBanner`, the Counselling page's status badges, from MCC notices) and her options as Options opens them (the round view while a round's seat lists are out): a stat strip and the label bars, each number linking to that Options view, then the history charts. 404 (`decide/not-found.tsx`), errors (`decide/error.tsx`) and "Data unavailable" (no database) render in the shell as an `EmptyState`.
- Content is left-aligned and divided by ruled hairlines and sheets, never floating shadowed cards. Headline numbers sit in one ruled **stat strip** (`StatStrip`), not as separate cards.
- Labels are sentence case. There are no all-caps eyebrows and no monospace labels.

## Charts (dataviz skill)
- Use the emphasis form: one accent (chart-ink blue) plus grey context. There are no categorical multi-hue series, because the palette validator failed our 4-hue set for colour-blind readers.
- Marks use `--color-mark` (`fill-mark`, `stroke-mark`, `bg-mark`); `sky` is for text and links. 2px lines, ≥8px markers with a 2px ring in the surface colour, bars at most 24px thick with a 4px rounded end. Grid lines are solid hairlines.
- Every chart has a legend when there are 2 or more series, selective direct labels, hover tooltips (value first, then label), and a "Show as table" view (`ChartCard`). A chart is one `role="img"` with a summary label; its marks are not tab stops (the strip has hundreds), the table view carries the numbers. Table views summarise (per course: count, deepest, median, shallowest) rather than list every option; the full list is the Options page.
- The memorable element is the **"Where your rank sits"** strip chart on faint ECG-style grid paper (`.chart-paper`), with the doctor's rank as the cursor line. Everything else stays quiet.
- Big standalone numbers use proportional figures. Table columns use `numeric` (tabular).

## Inside-app primitives (`src/features/decide/components`)
- `AppPage`: page frame (`min-w-0`; for grid pages use `grid grid-cols-1 gap-6`). `PageHead`: the h1 (`#main-h1`, focusable) and intro.
- `FilterBar` + `Field` + `Select` + `control` (ui.tsx): GET filter forms that keep the profile; Apply keeps focus. `FilterDropdown`: multi-select pill (one open at a time, closes on Escape and focus-out).
- `tbl` (ui.tsx): table classes; numbers right-aligned in `numeric`. `Pager` + `rangeLabel`: server-side pages, focus moves to the results heading. `StatStrip` / `StatCell`: headline numbers.
- `EmptyState` (ui.tsx, Astryx EmptyState on a dashed sheet): the one empty, no-results, not-found and unavailable state, with a heading and an action. `SetRankPrompt` uses it.
- `DataSource`: provenance under every data block, from the data (MCC result PDFs per year and round, term documents). `TermText`: a fee, stipend, bond or seat-leaving penalty exactly as published, with its source link. `termLabel` (types.ts) names them; PENALTY is "Leaving penalty / Round 2 forfeit" (its record says which: the college's or state's penalty for leaving the seat or course, MCC's forfeit if you resign or don't join from Round 2, or another penalty): never "bond penalty".
- Fees (`components/fees.tsx`, from `ProgrammeTerms`, server/terms.ts): `FeesSection` (one programme: one block per fee-table seat-type group (`FeeGroup`: the year table, NBEMS maximum / minimum badges, a verbatim fee as the profile's words and link with no fee column, MCC's three counselling form fields), else a Year table from the terms, a 2-year course has no year 3; one source numbering per programme: each group's, then the bond block's (only the sources it cites); Service bond (with its summary, "state rule" when that is the basis, "No bond" only where the college's document or the NBEMS rule says so, with the record's caveat in sun, the record's words where its status is unknown, and the college's own bond document linked where the status stands over it; years added up as "1 + 3 = 4 years") / Applies to / Leaving the course after joining / Other penalties / Resign or don't join from Round 2; the bond document's exact words (else the summary) in a closed details; numbered sources, each superscript a link named "Source N: …" so its name starts with the number shown), `TermsSummary` (one line: fee/yr · stipend yr 1 · bond yrs, ₹ · leaving ₹; "not declared" when missing, "unknown" when the record says so, "No bond (NBEMS rule)" / "(state rule)" / "(+ state rule)" (a state rule beside the college's document) from the record's basis, a no-bond caveat in the brackets ("No bond (NBEMS rule; private status inferred from name)"), "1 + 3 yr" for added-up years, a fee range as "₹1 L–₹68 L/yr", "up to ₹1.25 L/yr (NBEMS max)", "₹70,324 at admission, later yrs not stated" (a year the source leaves out is never shown as year 1's), "see terms" when declared in words only (or a fee shown as published), "+ more" when part is in words; the same bond figure as the Fees page, e.g. "up to ₹30 L (₹10 L × 3 yrs, computed)") on Options, Seats and Allotments rows (each row's `fees`: its course's programme, `courseTerms` in server/terms.ts; `termDocs` lists their documents for the `DataSource` under the rows) and the college Overview, `amountText` / `amountNote` (a bond or leaving `Amount`: range by course type, per-year × years, "incl. ₹10 L additional", varies by specialty), `Money` (full Indian grouping, with NBEMS maximum / minimum / paid at admission / NMC list markers), `NotDeclared` ("—" read as "not in our MCC data"). Missing is never "no bond", and never asserted about MCC itself: a programme with no bond record says "Not checked yet: Seatora has no bond record for this programme" (DNB and NBEMS Diploma with the NBEMS rule and its notices, MD/MS and Diploma with the state-bond caution), other missing values "Not in Seatora's MCC data yet". A source from an MCC profile that several institutes cite says it may be another institute's.
- Fees page (`/decide/fees`): a sortable table from md up (sticky institute column; header links read "Sort by …", the arrow is aria-hidden), one card per row below md (fee and stipend year 1, bond, leaving; sorting by the Sort by select). The less-used filters fold on phones behind "Show all filters" (an unnamed checkbox, `.more-toggle` / `.more-filter` in globals.css). Fee cell: year 1's figure, or "In words" (the profile gives the fee only in words, linking the Fees tab); whole course only where every year is stated. Bond and leaving cells: the highest ₹ figure with what it leaves out, "In words" (declared without a ₹ figure, linking the Fees tab), "None" / "No bond" (a record says no bond), "Unknown" (the record found no clear answer), or "—".
- `Provisional` (bits.tsx): the one warning marker, shown only when the data's source is provisional (`Source.provisional`, `GridCell.provisional`, `Deepest.provisional`); never tied to a year. `ReachBadge`, `Closing` (closing rank with its round and seat category), `Dash` ("—" with sr-only "not available").
- `SeatMatrix` (seats/seat-matrix.tsx): the wide Seats table: sticky institute column, grouped headers (round → clear/virtual, year → rounds), a Display column chooser (CSS on `data-col`, saved on the device) and a details drawer (Radix Dialog, no portal) per row. Its terms column is `TermsSummary` (fees.tsx) of the row's course, the drawer adds `TermSources`. Beds as the source prints them ("270+" where the value's own entry is flagged rounded; "conflicting" marked; the CSV's Beds note says both). Below `sm` the Display menu opens in flow under its button, never off-screen.
- `SubTabs`: link sub-navigation. `smallLink`: a 44px-tall link for notes and cross-links. Counts and ranks go through `formatRank` (Indian grouping).

## Adding inside-app UI
Prefer Astryx components (`npx @astryxdesign/cli component <Name>` for docs): Decide uses AppShell, SideNav, TopNav and EmptyState; tables, selects and filter bars are the Seatora primitives above. Where an existing Seatora component already fits, reuse it; the scoped tokens restyle it. Astryx CSS is imported only in `src/app/decide/layout.tsx`, but it stays loaded after a client navigation back to the site, so `globals.css` restates the site's `:root` border and colour scheme after the Astryx layers. Buttons: see [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) (md and icon are 44px).
